# 出荷関連帳票（製造完了後の3様式）

参考: `a0e0f867-_MT_______.xlsx`

製造完了後、各ロットについて以下3様式を作成・印刷・保管できるようにします。

| 様式 | データモデル | 印刷ルート |
|------|---------------|--------------|
| 出荷可否決定通知（様式1-1） | `ShipmentDecision` | `/manufacturing-orders/[id]/shipment-decisions/[sid]/print` |
| 市場への出荷記録（様式1-2） | `Shipment[]`（1ロット分まとめて） | `/manufacturing-orders/[id]/shipments/print` |
| 試験検査記録 | `TestInspectionRecord` + `TestInspectionItem[]` | `/manufacturing-orders/[id]/test-inspections/[tid]/print` |

## 1. 出荷可否決定通知（様式1-1）

### レイアウト

```
┌────────────────────────────────────────────────────────┐
│ 市場への出荷に係る記録            【別紙 様式１−１】 │
│                                                        │
│ （製造業者）すはだみらい研究所                         │
│                                                        │
│     ─── 市場への出荷可否決定通知 ───                   │
│                                                        │
│ 下記の製品の出荷の可否について、以下のとおり決定し… │
│                                                        │
│                  記                                    │
│   販売名：       __________________________            │
│   ロット・製造番号：______________________            │
│   数量：         __________________________            │
│                                                        │
│ ＜確認事項＞                                           │
│   製造所からの出荷可否の決定の記録：有(可・否)・無    │
│   当該製品の試験検査成績書       ：有(適・不適)・無 │
│   当該製品の品質及び安全性に関する情報：有＊・無      │
│   原材料等の品質及び安全性に関する情報：有＊・無      │
│   出荷判定基準逸脱等の有無と措置の確認：有(措置 適正・不適正)・無 │
│                                                        │
│ ＜特記事項＞                                           │
│ ＊情報、判断結果、理由を記載                           │
│                                                        │
│ ＜決定＞                                               │
│   市場への出荷の可否：可 ・ 否                         │
│   決定年月日：__________                               │
│   決定者：株式会社すはだみらい研究所                   │
│           品質保証責任者 髙橋 亜紀子          印       │
└────────────────────────────────────────────────────────┘
```

### データソース対応

| 帳票項目 | データソース |
|----------|--------------|
| 販売名 | `Product.salesName`（`ManufacturingOrder.product` 経由） |
| ロット・製造番号 | `ManufacturingOrder.lotNumber` |
| 数量 | `ManufacturingOrder.plannedQty`（または `completedQty`） |
| 確認事項 1 | `ShipmentDecision.check1ManufacturerDecisionRecord` |
| 確認事項 2 | `.check2TestReport` |
| 確認事項 3 | `.check3ProductQualityInfo` |
| 確認事項 4 | `.check4MaterialQualityInfo` |
| 確認事項 5 | `.check5DeviationCheck` |
| 特記事項 | `.specialNotes` |
| 決定 | `.decision`（APPROVED/REJECTED） |
| 決定年月日 | `.decidedAt` |
| 決定者 | `.decidedBy`（自由文字列。デフォルトは設定で固定可） |

### 印刷時の表示ルール

- 確認事項の選択肢は ◯ で囲む（CSSで対応）
- 「有＊」の項目は `specialNotes` に詳細が記載されているとマークする

## 2. 市場への出荷記録（様式1-2）

### レイアウト

```
┌────────────────────────────────────────────────────────────────┐
│ 製品の市場への出荷記録                     【別紙 様式１−２】 │
├──────────┬──────────┬──────┬────────┬──────┬──────┬────────┬──┤
│ 販売名   │ ロット番号│製造数量│出荷可否決定│出荷可否│出荷年月日│出荷先│… │
│          │ ・製造番号│      │ 年月日   │      │      │      │  │
├──────────┼──────────┼──────┼────────┼──────┼──────┼────────┼──┤
│          │          │      │          │可・否│      │      │  │
│          │          │      │          │可・否│      │      │  │
│ ...      │          │      │          │      │      │      │  │
├──────────┴──────────┴──────┴────────┴──────┴──────┴────────┴──┤
│ 特記事項 ：                                                    │
│                                                                │
│            製造販売業者確認欄                                  │
│   確認年月日：__________   品質保証責任者：髙橋 亜紀子  確認印 │
└────────────────────────────────────────────────────────────────┘
```

### データソース対応

ヘッダ行は固定。データ行は `Shipment[]` を時系列順に列挙。

| 列 | データソース |
|----|--------------|
| 販売名 | `Shipment.manufacturingOrder.product.salesName` |
| ロット番号 | `.manufacturingOrder.lotNumber` |
| 製造数量 | `.manufacturingOrder.plannedQty`（または `completedQty`） |
| 出荷可否決定年月日 | `Shipment.decisionDate` |
| 出荷の可否 | `Shipment.decision` |
| 出荷年月日 | `Shipment.shippedAt` |
| 出荷先 | `Shipment.destination` |
| 出荷数量 | `Shipment.shippedQty` |
| 在庫数量 | `Shipment.remainingStock` |
| 備考 | `Shipment.notes` |
| 特記事項 | 同ロットの `Shipment[].specialNotes` を集約 |
| 確認年月日・品質保証責任者 | 一覧の最終行（最新の `confirmedAt` / `confirmedBy`） |

### バリエーション

ファイルには「市場への出荷記録 (HC)」「市場への出荷記録 (ホウリン)」のシートもありますが、これは**出荷先別の集計シート**として印刷オプションで対応します（フィルタを `Shipment.destination` でかける）。

| 項目 | データソース |
|------|--------------|
| 販売名 | `TestInspectionRecord.manufacturingOrder.product.salesName` |
| 製造番号 | `.manufacturingOrder.lotNumber` |

### 簡易版

`isSimplified=true` のとき、試験項目テーブルの中身を「製造メーカーの試験成績書に準ずる」（または `simplifiedNote` の内容）の1行で表示する。

## 試験項目の初期値生成

`TestInspectionRecord` 新規作成時に、紐づく `Product.qualityStandard.testSpecs[]` を `TestInspectionItem[]` の初期値としてコピーすると、ユーザーは規格欄を埋め直さずに `result` と `judgment` を入力するだけで済む。

## 在庫との連動

`Shipment` が作成されると `remainingStock` を計算する（または `Product.stockQty` の状態をスナップショット）。
ManufacturingOrder ベースで「製造完成数量 − これまでに出荷した合計数量」で残在庫を算出する。
